\# TABBYFUND MASTER PROMPT

\## Part 6 — Design System, Brand Identity \& Visual Language



\# Design Philosophy



TabbyFund is not simply another animal rescue application.



It is a modern technology platform that combines compassion, trust, transparency, and community.



The visual design should feel:



Professional enough that users trust donations.



Friendly enough that users emotionally connect with rescued cats.



Modern enough to resemble a funded startup.



Cute enough to be memorable.



The design language can be summarized as:



"Cute, Calm, Trustworthy."



Avoid making the application feel childish.



Avoid making it feel overly clinical.



The ideal balance is:



Apple × Linear × Airbnb × Cat

\# Color Rules



Purple communicates trust.



Peach communicates warmth.



White creates breathing room.



Dark Slate improves readability.



Never use saturated red unless representing danger.



Avoid neon colors.



Avoid gradients unless subtle.



The interface should remain calm.

\# Empty States



Never leave empty screens blank.

Primary action



Mascot

\# Loading States



Prefer skeleton loaders.



Use mascot animations only for longer waits.



Never use infinite spinners alone.



\---



\# Success States



Celebrate meaningful actions.



Examples



Case reported



Donation completed



Treatment finished



Adoption successful



Use subtle animations.



Avoid excessive confetti.



\---



\# Photography



Cat photos should always have:



Rounded corners



Consistent aspect ratio



Lazy loading



Skeleton placeholders



High quality



Avoid distorted images.



\---



\# Accessibility



Minimum WCAG AA contrast.



Touch targets at least 44x44px.



Readable typography.



Visible focus states.



Color should never be the only indicator.



\---



\# Responsive Philosophy



Design mobile first.



Optimize for:



375px



390px



430px



Then progressively enhance for:



Tablet



Desktop



Wide screens



Desktop should feel like an extension of mobile.



\---



\# Overall Product Feeling



When someone opens TabbyFund for the first time, they should immediately think:



"This feels polished."



"I trust this platform."



"I want to help."



"This app genuinely cares about stray cats."



The design should create emotional engagement without sacrificing professionalism.



Every pixel should reinforce the mission of making stray animal rescue simple, transparent, and community-driven.
