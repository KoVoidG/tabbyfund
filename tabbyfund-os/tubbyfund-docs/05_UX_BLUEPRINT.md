\# TABBYFUND MASTER PROMPT

\## Part 5 — User Experience Blueprint



\# UX Philosophy



Every screen exists to reduce friction.



Users should never wonder what to do next.



Every screen should have one clear primary action.



Never overwhelm users with too many choices.



Guide them step by step through the rescue journey.



The application should feel warm, trustworthy, and emotionally engaging while remaining professional.



Every page should reinforce one idea:



"Together, we can save this cat."
