## Development Workflow

For every implementation:

1. Read only the relevant docs.
2. Explain understanding.
3. Produce an implementation plan.
4. Wait for approval.
5. Implement in small, reviewable commits.
6. Perform a self-review.
7. Recommend the next logical task.

Never implement multiple major features in one session.
Never rewrite unrelated code.
Treat the documentation as the single source of truth.
